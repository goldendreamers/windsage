Local Agent

This APK opens a local agent on this phone (127.0.0.1:8790 in Termux). It is not cursor.com/agents and not a cloud VM.

Uninstall the old Cursor Agent icon first (that one was a cloud shortcut). Then install this file.

Download Local Agent v5 (APK)

After install: if the app says the local agent is not running, open Termux once so sshd + the local-agent service stay up, then reopen the app. You must finish cursor-agent login in Termux (one-time).

cursor.com/agents is a different thing (cloud). Do not use that if you want Wald SSH from this phone.
