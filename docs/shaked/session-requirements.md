## 2. יעד קשיח: 100 משתמשים

הלקוח דורש תמיכה ב־**100 משתמשים רשומים** (לא מיליון, לא שלושה חברים בלבד).

פירוש הנדסי שצריך לקבל או לדחות עם נימוק:

- **100 חשבונות + follows + snapshots ב־`store.json`** — סדר גודל קטן (מגהבייטים בודדים). JSON + cache + תור כתיבה **מספיקים** ליעד הזה, אם נשאר תהליך Node אחד ותור סידורי.
- **100 כותבים במקביל לכל פול** — לא היעד. הפול כבר עם concurrency מוגבל.
- **100 בשרת Discord שקוראים `/v1`** — לגיטימי; הם לקוח נוסף לאותו API.
- **לא** לפצל מיקרו־סרביסים ו־Postgres “כי 100 זה סקאלה”. כן להגדיר **טריגר החלפה ל־SQLite מאחורי אותו `/v1`**: קובץ > ~5MB, פול > ~30 שנ׳, תור כתיבה שמתארך, או צורך בשאילתת היסטוריה.

`R-100` — תאשר או תדחה את פסק הדין הזה מול `code/cloud/lib/store.mjs` ו־`server.mjs`.

## 4. Best practice — פיתוח מול LLM (חובה ללמוד ולהפגין)

הלקוח מצפה שתעבוד כמו ספק בכיר, לא כמו autocomplete. הרף:

### 4.1 לפני קוד
1. קרא את הענף האמיתי (`git log -5`, `git status`).  
2. קרא את קובץ הדרישות הזה + `docs/FRIEND_GROUP_VISION_2026-08-21.md`.  
3. בדוק חי: `https://windsage.nimrod.bio/health`.  
4. אם חסר מזהה Discord/VAPID — **עצור ובקש**, אל תמציא.

### 4.2 בזמן קוד
5. Expo = תיעוד גרסה, לא StackOverflow מהזיכרון.  
6. שנה את המינימום. אל “תנקה” מסביב.  
7. גבול API קיים — הרחב `/v1`, אל תדלג ל־`store.json` מהלקוח.  
8. כתיבה ל־store רק דרך `saveStore` (תור, tmp, סירוב wipe).  
9. בדיקות קיימות: `npm run check`, `node scripts/check-geo.mjs` לפי הצורך.  
10. אין `release:web` מ־VM בלי Tailscale/Wald.

### 4.3 אחרי קוד
11. PR קטן, תיאור: מה, למה, איך בדקת, מה לא נגע.  
12. דוח סשן עם טבלת R-…  
13. אם דחית דרישה של הלקוח — זה ציון **גבוה**, בתנאי שיש ראיה.

### 4.4 כשלים נפוצים שנפסול
- אישור כל ההמלצות כי “נשמע נכון”
- מיזוג טיוטה שמנה כי “חבל על העבודה”
- LLM לכל הודעת Discord
- Postgres “כדי להיות מוכנים למיליון”
- הודעת “סיימתי” בלי URL / פקודה
- נתיבים יחסיים שבורים בצ’אט
- המצאת API של Expo
- דריסת `store.json` ב־rsync (ה־exclude של `data` קיים ב־`release-web.py` — לא לעקוף)

רפרנס פנימי: `CLOUD_AGENT_CONTEXT.md`, `docs/AGENTS.md`, `docs/WEEKLY_REVIEW_2026-08-21.md`.  
רפרנס חיצוני: [Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/), [Discord slash commands](https://discord.com/developers/docs/interactions/application-commands) (0 עלות טוקני מודל), [Discord webhooks](https://discord.com/developers/docs/resources/webhook).
